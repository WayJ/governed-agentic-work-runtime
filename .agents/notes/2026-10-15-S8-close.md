## Lessons

- The doc-sync same-commit rule bites when owners ship code and docs in
  separate commits; integration should check the runtime.py↔boundaries pair
  at review time, so consolidation is never needed at merge time.
- Owner prose counts (new tests, gate file totals, skip reasons) need
  fresh-discovery reconciliation every acceptance; three separate slips were
  caught this sprint without any product change.
- A harness that cannot display images can still produce first-class visual
  evidence: live CDP computed styles/contrast + exact-match stdlib pixel
  forensics of committed captures + a human (root coordinator) viewing pass
  of the narrow-viewport PNG — each labeled for what it does and does not
  prove.
