## Lessons

- **Independent design review pays for itself again**: the IR-F1 key-collision
  counter-probe forced a one-line amendment before any code existed; the
  drafted key would have shipped a provable collision. The design→review→
  ratification→materialize pipeline is now three-for-three (S10, S11, S12).
- **The ask channel works**: the W2 blocking question was precise (probe
  evidence + three options + cost estimates); a scoped authorization resolved
  it without scope creep or a silent deviation.
- **Count reconciliation discipline**: the integration worker explained the
  acceptance record's 103/492 vs merged 104/496 contracts delta exactly
  (+1 file/+4 links = the acceptance record itself) — keep requiring such
  reconciliation instead of letting counts drift unexplained.
