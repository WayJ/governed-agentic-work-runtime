## Lessons

- A filter-matched zero-test run prints `OK` and is not RED evidence: to observe a regression
  test fail on an old tip, the corrected tip's test file must be laid onto the old code. This
  caught what a plain `-k` run would have greenwashed.
- PASS stdout is not release proof: the demo's first installed verification checked only
  printed text; the correction added direct per-store SQLite counts for both entry points —
  the release gate now demands independent counts, not transcripts.
- Small owner corrections (one guard, one explanation string) still warrant independent
  RED/GREEN reproduction — each of the three S3 corrections would have shipped a wrong
  guarantee had review trusted the owner's green run alone.
