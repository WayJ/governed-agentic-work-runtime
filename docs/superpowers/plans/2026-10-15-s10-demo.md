> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the S10 demo wave — a no-credentials `compensation-demo` (real child crash, withdrawn effect, refusal-not-reversal), its CLI subcommand, independent installed module+console verification, and truthful bilingual docs — without touching any core/protected source.

**Architecture:** A new `work_runtime/compensation_demo.py` mirrors the `revocation_demo` house pattern: two scenarios on separate fresh stores, every count asserted against SQLite, printed `inspect` paths. **Tech Stack:** Python ≥3.9, stdlib only, unittest, SQLite.

## Review Focus

1. **False CLI capability claim** — a reviewer may assume the shipped `worker` subcommand can execute the withdrawal; it holds `AUTHORITY_DENIED` (verified). Pinned by `test_shipped_worker_cli_cannot_withdraw` (Task 2).
2. **Counts trusted from stdout** — every printed count must be re-derived from SQLite in tests and the installer proof, never parsed from narration. Pinned by store-reading tests (Task 1) and `require_compensation_proof` (Task 3).
3. **Fake reversal/original deletion** — the demo must show the forward effect retained (accepted_count stays 1, invoices/receipts untouched, E08 still satisfied by the real forward proof), history appended not deleted. Pinned by Task 1 store tests + installer proof.
4. **Refusal misread as failure/unknown** — the `ORIGINAL_ABSENT` scenario is an authoritative stored rejection (`confirmed_failed` + queryable receipt + adapter_result), not `outcome_unknown`; the closure ack names only the succeeded original. Pinned by Task 1 refusal tests + installer refusal proof.
5. **Withdrawn proof confused with forward accepted proof** — kind `withdrawn` with `{digest, external_id, original_external_id}` at the withdrawal identity; it must never satisfy or replace the forward accepted proof. Pinned by Task 1 proof tests and `test_proof_rejects_flipped_proof_kind` (Task 3).
