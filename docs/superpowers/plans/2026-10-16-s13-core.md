## Review Focus

1. **Cross-shape evidence must never crash verification:** a `card_approval` recorded on a withdrawal work, or a `card_withdrawal` on a card work, must return `False` from `validate_evidence` (candidate → `invalid`) — a naive branch hits `KeyError` on the missing `policy`/`policy_version` field and escapes `verify_pending` unbounded. → Task 3 pins both directions.
2. **The refused receipt must validate against the operation:** `receipt_is_valid` compares `result["digest"]` to the op's document digest, so the wrapper's rejected receipt must carry exactly the `content_digest` argument it was called with — otherwise `_resolve` quarantines (`ADAPTER_RESULT_INVALID`) instead of confirming failure. → Task 1 pins the receipt digest; Task 3 pins the governed `confirmed_failed` outcome.
3. **Withdrawal reads must not create directories:** `FilePublisher(directory)` runs `makedirs`, so every withdrawal read guards `os.path.isdir` first (the S12 loader discipline) — a missing store must stay missing. → Task 2 pins `withdrawal_record()` and the loader on a never-created directory.
4. **Adapter corruption vocabulary must not leak (RV-F5):** every `read_validated` violation class on the withdrawal record maps by explicit catch-and-re-raise onto the one invalid-record message — the loader surface stays six bounded classes, never a seventh. → Task 2 pins corrupt bytes, stale-digest tamper and a foreign record under the withdrawal key.
5. **Wrong-adapter dispatch must never reach `execute` (D70):** a `sop.withdraw` operation dispatched through `SopPublicationStore` holds `ADAPTER_ACTION_UNSUPPORTED` with zero attempts (the contract preflight at `runtime.py:1029-1036`) — pin it so a mismatched pair can never commit a store write. → Task 3 pins the hold and the re-dispatch recovery.
