# S10 W1 Expense-Compensation Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the master-ratified (v2.1, D43–D48) expense-only
active-cancellation compensation slice: linked `propose_action` variant, opt-in
adapter action/link context, FakeOA withdrawal store, `withdrawn` proof kind,
stored adapter results and truthful closure — with meaningful RED/GREEN TDD and
same-commit boundary docs.

**Architecture:** One runtime carve-out (compensation proposals exempt from the
cancellation gate, dispatch revalidation, resolution binding), one adapter
protocol extension (`supports_action_context` opt-in; legacy three-positional
calls byte-identical), and an additive FakeOA store migration (nullable
`receipts.action`/`link_digest`, new `withdrawals` effect table). Reconcile,
recover, CAS/replay and the S9 conflict machinery are reused unchanged.

**Tech Stack:** Python ≥3.9, standard library only, `unittest`, SQLite. Schema
stays `1` (runtime store); the adapter store migrates additively under
`BEGIN IMMEDIATE`.

**Spec:** `docs/superpowers/specs/2026-10-15-compensation-execution-design.md`
— §14 (DRAFT v2) as amended by §15 MASTER ratification v2.1 (D43–D48, which
resolve A1–A4/C1–C4/m1–m5/MD1–MD5 and override conflicting v1/v2 text).
Secondary: `.agents/notes/2026-10-15-compensation-independent-design-review.md`
(F1–F9), `.agents/notes/2026-10-15-compensation-independent-design-review-v2.md`
(A1–A4, C1–C4), `docs/superpowers/sprints/2026-10-15-S10-plan.md`,

5. **A compensation resolves against the wrong original** (wrong
   `original_external_id` in the receipt — C1) →
