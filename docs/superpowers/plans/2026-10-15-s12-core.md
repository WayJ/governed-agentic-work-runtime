## Review Focus

1. **Store-key collision (IR-F1/IR-P16):** delimiter-hostile ids like `("collide:one","v1")` vs `("collide","one:v1")` must yield different keys — Task 2 pins non-collision plus key-shape (`"sop-pub:" + 64 hex`).
2. **Read-path side effects / unbounded OS errors:** a loader on a missing store directory must fail with the bounded absent error, not `OSError` from `makedirs`, and must not create the directory — Task 3 pins missing-directory behavior.
3. **Doctored store content under a valid key (cross-database sharing, MD-4):** a non-card document or a different card committed under the requested key must fail closed (lint/identity), never load — Task 3's fail-closed matrix.
4. **Conflict masked by blockers (IR-F3/D66):** `_propose` checks requirement blockers before the business-key branch, so a second same-version work is first `REQUIREMENT_UNSATISFIED` and only `OPERATION_CONTENT_CONFLICT` after its own verified approval — Task 4 pins both stages in order.
5. **Loader silently degrading:** absent version must raise (not return None), corrupt and absent must be distinguishable bounded `ValueError`s, `pinned_card` must refuse a wrong pin — Task 3 pins each; `read_validated` must apply the full validation matrix (never an unvalidated parse) — Task 1 pins artifact equality + corruption refusal.
6. **Rotation touching publication history:** approver-key rotation refusals must leave all six runtime tables and the store directory bytes untouched — Task 5 pins byte-level preservation.
