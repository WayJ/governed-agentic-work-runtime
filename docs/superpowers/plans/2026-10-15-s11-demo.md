## Review Focus

1. **Digest claim overstates the writes** — the new-command resend legitimately appends exactly one `commands` row, so the six-table digest cannot be byte-identical across that step; the demo must print the decomposition truthfully (byte-identical across every zero-write rotation act: boundary replay, retired refusal, same-command re-sign; after the new command: five tables byte-identical, `commands` = before + exactly 1 row) and the PASS line says `history rewritten: 0`. Pinned by store-reading tests (Task 1) and `require_rotation_proof` (Task 3).
2. **Narrative trusted from stdout** — every printed count (2 evidence rows, +1 command row, statuses, digests) must be re-derived from SQLite in tests and the installer proof; the proof recomputes the six-table digest and the evidence fingerprints with the standard library only. Pinned by Task 1 store tests + Task 3 proof (including its negative tests).
3. **"Cached receipt verbatim" faked by a fresh receipt** — the same-`command_id` re-sign must return the *stored original* receipt (its `evidence_status` stays `"pending_verification"`) while the evidence row's current status is `"verified"`; the store keeps exactly one `commands` row for that id. Pinned by Task 1 (`test_store_cached_receipt_row_is_the_original`) and Task 3 (`test_proof_rejects_tampered_cached_receipt`).
4. **Secret leakage through output** — key ids (`finance-2026-08`, `finance-2026-10`) are public data; secrets and signatures are not: no 64-hex token may appear anywhere in demo output. Pinned by `test_output_pins_narrative_without_secret_material` (Task 1).
5. **Retired refusal confused with authentication failure or expiry** — at `T0+301` the replayed original envelope is both past the key window and stale; the gateway must report `EVIDENCE_KEY_RETIRED` (window precedes freshness, post-HMAC, minimal receipt) with the cached receipt unreachable and zero writes. Pinned by Task 1 store-digest tests and the demo's own asserts; the code constant comes from the frozen core, never a reimplementation.
