> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline; no subagents — the dispatch forbids extra agents) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configuration-supplied per-source signing-key rings with validity windows and an authenticated optional `key_id` envelope selector, in `work_runtime/ingress.py` alone, exactly per master ratification D49–D53 (which override conflicting DRAFT text) with review amendments F1–F4/M1–M4 folded in.

**Architecture:** Additive change to the existing HMAC gateway: a `SourceKey` NamedTuple and per-source ring normalization/validation at construction; envelope shape admits one optional signed field (`key_id`) with `SIGNED_FIELDS` and the published KAT untouched; deterministic key selection (no try-all, no fallback) before HMAC; one finite clock sample shared by the new inclusive key-window checks and legacy freshness, all before `runtime.command`. No store, schema, runtime, policy or authority change — rotation is a configuration act.

**Tech Stack:** Python ≥3.9 standard library only (`hmac`, `hashlib`, `math`, `time`, `typing`); stdlib `unittest`; real SQLite runtimes in tests.

**Spec:** `docs/superpowers/specs/2026-10-15-source-key-rotation-design.md` — DRAFT §4 plus **MASTER ratification D49–D53 (2026-10-15) which overrides conflicting DRAFT text**; independent review `.agents/notes/2026-10-15-source-key-rotation-independent-design-review.md` (F1–F4, M1–M4); sprint `docs/superpowers/sprints/2026-10-15-S11-plan.md`; RFC-003 §3 D16.

## Review Focus

1. **Legacy regression** — any drift in the legacy bytes path (validation order, freshness boundary at `±max_age`, `ENVELOPE_FIELDS` meaning) breaks the untouched 40-test pin. Task 2/3 keep legacy code paths byte-equivalent in behavior; Task 4 re-pins.
2. **Huge-int clock overflow** — `math.isfinite(huge_int)` itself raises `OverflowError` (D51: validate finiteness "safely on huge ints"); only floats pass through `isfinite`; freshness uses comparison-only form so no float/int subtraction can overflow. Pinned in Task 3.
3. **Live caller alias** — `dict(keys)` is shallow; a caller's list-valued ring would stay live-connected (F3). Rings normalize to immutable per-source tuples; Task 1 mutates outer dict AND inner list.
4. **Silent retired-key acceptance** — a no-`key_id` envelope must authenticate against the ring's `current` entry ONLY (SKR-7); a legacy-format envelope signed with a retired key fails HMAC against the current key, never falls back. Pinned in Task 2.
5. **Receipt/key-material leakage** — new codes must stay minimal `{"decision","code"}` with no key echo (B1). Pinned in Task 4.
