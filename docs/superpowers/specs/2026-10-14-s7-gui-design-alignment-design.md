# S7: operations viewer design alignment

Date: 2026-10-14. Coordinator choice under the user-reactivated continuous goal. Read AGENTS.md, DESIGN.md, docs/gui.md, docs/gui-api.md and the S5 design first. This applies a newly supplied design reference prospectively; S5 was not accepted against DESIGN.md.

## Intent and scope

Make the existing offline, bilingual read-only operations viewer visually coherent with the public developer website and DESIGN.md while keeping its real information density, exact stored truth and interactions. Users must still find work, inspect blockers, evidence, operations, decisions, event sequence and raw records. No lifecycle controls, invented model stages, copied Cursor brand/copy, new runtime guarantees or marketing components.

The implementation remains vanilla HTML/CSS/JavaScript served by the current stdlib server; Python >=3.9, zero runtime dependencies, no new frontend build, CDN, assets or bundled fonts. Target work_runtime/web/app.css primarily; index.html/app.js only for justified accessibility/layout corrections with observed meaningful browser RED/GREEN. Backend, policy, schema, DTOs, exact raw rendering and polling state machine are preserved.

## Visual contract and coordinator adaptations

Central CSS variables define all applicable color, typography, spacing, radius and responsive choices. Canvas #f7f7f4, ink #26251e, body #5a5852, white cards, hairlines #e6e5e0/#cfcdc4, scarce orange #f54e00, active orange #d04200; no drop shadows. Repeated literal component values become token references. Controls radius 8px, cards 12px, 4px spacing scale. System sans plus readable Chinese fallback; locally available JetBrains Mono plus system monospace. No licensed font redistribution.

Operations headings use display 26px/22px, weight400; component labels 16px/18px weight600; body14–16px and raw/code13px. No 72px hero or 80px between operational rows. Negative tracking only display text, Chinese tracking zero. Compact 12–24px panel spacing is a documented adaptation. Breakpoints follow <640,640–1024,1024–1280,>1280: single-column under1024; wider two-pane view with 1200px content cap. At320px controls wrap and every panel is reachable. Long identifiers and raw data wrap or scroll within their own surfaces; never hide document overflow to make broken layouts appear to pass.

Orange/white normal text is only ~3.52:1 and ink/orange ~4.37:1. Default primary refresh controls use ink/canvas; orange may be a restrained non-text accent, or white/#d04200 if independently measured >=4.5:1. Small muted text uses body color; do not copy DESIGN muted #807d72 when actual contrast fails. Visible focus uses a contrast-verified outline; actionable controls have >=44px touch height (documented improvement over reference40px). Status text stays explicit and colors use measured accessible semantic adaptations, not timeline pastels. Neutral work selection uses hairline/ink and a programmatically selected state; avoid blue action palette. Timeline preserves actual stored events and logical sequence with neutral presentation; no thinking/grep/read/edit mapping.
